# Запуск сканера: запасной путь

Основной запуск описан в шаге 1 SKILL.md:
`python3 <папка скилла>/scripts/scan.py файл.txt` (текст без файла через `-`
на stdin, жанр через `--genre`, исходник для сверки через `--before`).

Если `scan.py` упал с «не хватает зависимостей», сам ничего не ставь: ни
`pip install`, ни `uvx`, ни `pipx`. Зависимости ставит пользователь один раз
командой `bash <папка скилла>/scripts/setup_venv.sh` (venv с зафиксированными
версиями и хешами), после этого `scan.py` сам находит этот venv.

Работай вручную. О недоступности сканера скажи одной строкой, только если
пользователь сам просил балл или аудит, и назови эту команду. Балл на глаз не
придумывай.
